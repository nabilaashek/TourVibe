About

TourVibe: Pack, Go & Explore Bangladesh

TourVibe is the new version of our Pack-Go project. It helps travelers find places in Bangladesh, choose the right season, estimate the cost of a trip and book tour packages.

Find places

Search by division, type, month and budget. Every place has its best months, daily cost, tips, photos and reviews.

Cart and checkout

Add tour packages to the cart and book them in one order. Seats are checked so a tour is never overbooked.

Trip planner

Orders your places into a short route (nearest-neighbour method) and estimates transport, hotel, food, tickets and a 10% extra.

Where to go?

Scores places out of 100 using season, budget, interests and ratings, and shows the reasons.

Built with

  • Python and Django (MVT pattern), SQLite
  • Django REST Framework with token login - open the API
  • Bootstrap 5, Chart.js and JavaScript
  • ReportLab for PDF invoices
  • Automated tests: python manage.py test
